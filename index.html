Where are the arrays?

The key idea for your presentation
1. Student names array

Stores each student's name at an index.

studentNames[0] → "Ama Mensah"
2. Student marks array

Stores the mark at the matching index, so the name and mark stay linked by position.

studentMarks[0] → 95
3. Traversal with a loop

A loop visits the arrays from index 0 through the last index to display results and calculate the average.

for (let i = 0; i < studentNames.length; i++)
4. Finding the highest mark

The app compares the marks to find the largest value and displays the matching student's name.

Math.max(...studentMarks)
